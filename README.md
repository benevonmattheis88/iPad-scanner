# iPad-Scanner

Liest die Strichcodes der Bestandsnummern auf den iPads mit der Handykamera, sammelt sie in Listen und schickt eine Liste per E-Mail an ipads@wilhelm-remy-gymnasium.de.

- Öffnen: https://benevonmattheis88.github.io/iPad-scanner/
- Die Seite lädt nichts nach und sendet nichts. Die gescannten Nummern bleiben im Browser des Handys, bis sie per E-Mail verschickt werden.
- Enthält [@zxing/library](https://github.com/zxing-js/library) 0.21.3 (Apache License 2.0, siehe LICENSE-zxing.txt).
